[BaekJoon-1158] 요세푸스 문제(Josephus of problem)

문제

요세푸스 문제는 다음과 같다.

1번부터 N번까지 N명의 사람이 원을 이루면서 앉아있고, 양의 정수 K(≤ N)가 주어진다. 이제 순서대로 K번째 사람을 제거한다. 한 사람이 제거되면 남은 사람들로 이루어진 원을 따라 이 과정을 계속해 나간다. 이 과정은 N명의 사람이 모두 제거될 때까지 계속된다. 원에서 사람들이 제거되는 순서를 (N, K)-요세푸스 순열이라고 한다. 예를 들어 (7, 3)-요세푸스 순열은 <3, 6, 2, 7, 5, 1, 4>이다.

N과 K가 주어지면 (N, K)-요세푸스 순열을 구하는 프로그램을 작성하시오.

입력

첫째 줄에 N과 K가 빈 칸을 사이에 두고 순서대로 주어진다. (1 ≤ K ≤ N ≤ 5,000)

출력

예제와 같이 요세푸스 순열을 출력한다.

예제 입력 1

7 3

예제 출력 1

<3, 6, 2, 7, 5, 1, 4>

풀이

큐를 이용하여 문제를 해결 할 수 있다.

N 이 7 이고 K 가 3 일 경우

  1. K번 째가 되기 전 까지 맨 앞 데이터를 꺼내어(poll) 다시 queue에 맨 뒤에 삽입(offer) 한다.
  2. K 번째가 되었을 때 맨 앞 데이터를 꺼내어(poll) list에 담거나, 문자열에 담는다.

끝.

원을 큐로 나타내는 이유

큐의 앞은 현재 셀 사람이고 뒤는 그 사람 다음에 올 순서다. K−1명을 앞에서 꺼내 뒤로 돌리면, K번째 사람이 앞에 온다. 그 사람을 제거하고 바로 다음 사람부터 다시 세면 원을 한 바퀴 돈 것과 같다. (7, 3)의 첫 단계는 1과 2를 뒤로 보내 3을 제거한다. 남은 순서는 4, 5, 6, 7, 1, 2이고, 같은 동작으로 6을 제거한다.

코드에서 cnt는 현재 앞사람이 몇 번째 차례인지 나타낸다. 제거한 뒤에는 1로 되돌리고, 나머지 차례에는 poll한 사람을 offer로 다시 넣는다. 출력의 쉼표는 큐가 아직 비지 않았을 때만 붙이므로 끝에 불필요한 쉼표가 없다. N=K=1이면 한 명을 곧바로 제거해 <1>이 된다.

한 사람을 제거할 때 최대 K번의 큐 연산이 있으므로 시간은 O(NK), 큐와 출력 버퍼는 O(N) 공간을 쓴다. N이 5,000인 이 문제에서는 큐로 동작을 그대로 재현하기 쉽다. 큰 N에서 최후 한 사람만 찾는 문제라면 수열 전체를 출력하지 않는 점화식을 고려할 수 있지만, 여기서는 제거 순서 전체가 필요하다.

제거한 사람제거 직후 큐의 앞→뒤
시작1, 2, 3, 4, 5, 6, 7
34, 5, 6, 7, 1, 2
67, 1, 2, 4, 5
24, 5, 7, 1

큐의 물리적 배열이 처음의 원형 자리와 같을 필요는 없다. 맨 앞이 다음에 셀 사람이라는 불변식만 유지하면 제거 후의 순서를 그대로 재현한다. 출력 목록을 만들기 전에 몇 단계만 적어 보면 K−1명 회전 후 제거하는지, K명 회전한 뒤 제거하는지의 한 칸 차이를 잡기 쉽다.

소스코드

import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;
import java.util.*;

public class Main {


    public static void main(String[] args) throws Exception {
        josephus();
    }

    public static void josephus() throws Exception {
        BufferedReader in = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter out = new BufferedWriter(new OutputStreamWriter(System.out));

        String[] input = in.readLine().split(" ");
        int n = Integer.parseInt(input[0]);
        int k = Integer.parseInt(input[1]);

        Queue<Integer> queue = new LinkedList<>();

        for (int i = 1; i <=n; i++) {
            queue.offer(i);
        }
        int cnt = 1;
        StringBuilder sb = new StringBuilder("<");
        while (!queue.isEmpty()) {
            if (k == cnt) {
                cnt = 1;
                sb.append(queue.poll());
                if (!queue.isEmpty()) {
                    sb.append(", ");
                }
            } else {
                cnt++;
                queue.offer(queue.poll());
            }
        }
        sb.append(">");
        out.write(""+ sb.toString());
        out.flush();
        out.close();
        in.close();
    }
}
